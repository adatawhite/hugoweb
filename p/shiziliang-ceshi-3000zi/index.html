孩子快上小学了，认字到底行不行？现在多少基础才够用？

与其凭感觉猜，不如直接测一下。

今天分享一套**《3000字识字量测试》**，覆盖小学阶段常用字，一共55页、3000个字。打印出来让孩子逐字勾选，认识多少一测便知。

每页约70个字，认识的在括号里打勾即可，操作简单

为什么要测？

识字量决定阅读能力。

识字量500字 → 读带拼音绘本。识字量1000字 → 尝试桥梁书。识字量2000字 → 独立阅读纯文字儿童读物。

选对书，孩子才愿意读。测一次，心里就有底。

不认识的字直接跳过，结束后统计打了多少个勾就是总识字量

怎么测？

  1. 打印出来（A4纸双面打印，约28张纸）
  2. 让孩子逐字看过去，认识的字打勾，不认识直接跳过
  3. 分次完成，一次5-10页，避免疲劳
  4. 打完统计总数

如果孩子识字量低于标准，多读拼音读物补基础；高于标准，就加大阅读难度。
